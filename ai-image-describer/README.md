# AI Image Describer

This is a desktop application for managing and describing images using AI.

## How to Run for Testing

1.  **Install Dependencies:**
    ```bash
    npm install
    ```

2.  **Run the Application:**
    ```bash
    npm start
    ```

This will launch the application in development mode. You can then test the following features:

*   **Folder Management:** Click the "Manage Folders" button to add and remove folders.
*   **Image Display:** Images from the added folders should appear in the main grid.
*   **Description Editing:** You can click on the text area below each image to edit its description. The description will be saved automatically.
